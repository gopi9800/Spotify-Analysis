# Spotify Listening Analysis — Power BI Dashboard

## Overview

This project is a Power BI dashboard created to analyze Spotify listening history and understand listening patterns across albums, artists, tracks, platforms, and time.

The dashboard explores listening activity over time and provides interactive views of listening behavior.

## Business Questions

- How many albums, artists, and tracks were played?
- How has listening activity changed over the years?
- Which albums and artists were played the most?
- Which tracks were played most frequently?
- How does listening differ between weekdays and weekends?
- Which platforms were used for listening?
- At what hours of the day is listening activity highest?
- How does track frequency relate to average listening time?
- How does listening behavior vary by year?

## Dashboard Analysis

### Albums & Artists

The dashboard tracks albums and artists played over time and highlights the top albums and artists based on total play counts.

### Track Analysis

Tracks are analyzed based on play frequency and listening time, including the relationship between track frequency and average listening duration.

### Listening Patterns

Listening behavior is analyzed across:

- Day of week
- Hour of day
- Year
- Weekday vs weekend
- Listening duration

### Platform Analysis

The dashboard provides platform-level analysis, including Android, iOS, Mac, Web Player, Windows, and other listening devices.

### Detailed Listening Data

The details view provides album-level records including number of albums, artists, tracks, and milliseconds played.
